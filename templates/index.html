Machine Learning Pipeline

The detection engine uses a production-ready scikit-learn pipeline composed of feature extraction, robust numerical scaling, categorical one-hot encoding, and an ensemble Random Forest classifier.

Data Leakage Prevention Guard:

Source markers (e.g. dataset column) and direct identifiers (handles, names, user IDs, image URLs) are strictly excluded from the model pipeline. Predictions rely solely on behavioral statistics and profile configuration attributes.
